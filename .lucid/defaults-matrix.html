hcn reference

Bare-run defaults across the four harnesses

What each run looks like when the CLI is invoked with nothing but a prompt - hcn run <harness> "prompt". Every option is omitted, so each run is the descriptor's pinned base flags plus whatever the harness below decides on its own.

Sources: descriptors in src/knowledge/, argv captured with hcn inspect --argv · verified against claude 2.1.233, codex 0.147.0, pi 0.84.2, muse 0.1.0

The spawn

The exact argv each harness receives. Accent marks the flags hcn always injects regardless of options; everything else is the harness's own headless surface.

claude -p <prompt> --output-format stream-json --verbose --include-partial-messages
codex exec --json --skip-git-repo-check --sandbox workspace-write <prompt>
pi -p --mode json <prompt>
muse exec --json <prompt>

Codex's --sandbox workspace-write is the only turn option with a descriptor-level default; it is emitted on launch only, because codex exec resume rejects --sandbox.
