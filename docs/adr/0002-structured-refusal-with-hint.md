# Refusals carry a hint before the support list

Every `rejected` FailureSummary carries two structured fields derived at runtime from descriptor data, never hardcoded: `supportedBy` (which harnesses support the option and their native spellings) and `hint` (the nearest-alternative control on the CURRENT harness). The human rendering and the structured order are hint first, support list last, so a scanning agent meets the stay-on-harness suggestion before the temptation to switch harnesses. Hint wording is curatorial, versioned, and pinned verbatim.
